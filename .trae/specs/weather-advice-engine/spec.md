# Plaza Venezuela 天气模块智能建议引擎升级规格

> 上一轮交付对应 spec：`[spec.md](file:///h:/GitHub/plazavenezuela/.trae/specs/pv-seo-content-upgrade/spec.md)`；本轮是对天气模块（Weather.astro）的独立升级，不改动其它章节。

## 问题

当前 [Weather.astro](file:///h:/GitHub/plazavenezuela/src/components/Weather.astro) 仍偏「气象数据面板」：打印温度/湿度数值 + 4 枚静态徽章。普通游客（占流量 70%+）不会自己推导「降水概率 65% = 出门必须带折叠伞吗？昼夜温差 10℃ = 放一件外套在包里？风力 32km/h = 在喷泉天桥拍照会不会吹掉帽子？」。用户明确要求：**基于天气组合直接输出可执行建议，不用用户自己思考「这代表我该干嘛」**。

同时，原模块没有根据 Plaza Venezuela 的具体地理环境（首都人文广场 + 邻接 Los Caobos/Jardín Botánico 绿地森林 + 加拉加斯距海岸 ~25km 沿海大都会）扩展场景化建议。

## 目标用户

- 首次到访的境外中文游客：做「今天出门穿啥/带啥/怎么安排」的 3 秒决策。
- 亲子家庭、老年/低体力人群：对温差、防晒、防滑、风险的敏感度更高。
- 摄影游客：关心「光线是否柔和/是否适合蓝调夜景/三脚架是否会被风吹倒」。
- 爬虫：页面正文更丰富，提高语义密度（非本 spec 主目标，附带收益）。

## 目标

1. 把原「数字面板」升级为「建议引擎」：在基础天气卡片后，按优先级输出 4 类动态条目。
2. **动态渲染（核心约束）**：不满足条件的条目 → 整条卡片/区块直接不渲染（不下雨就永远看不到任何「雨伞」字样；无风害看不到「注意裙摆帽子」）。
3. **地理扩展**：针对 Plaza Venezuela 的三类周边场景（城市广场人文 / 邻接绿地森林 / 沿海大都会距海近），在条件命中时追加场景专属建议（否则不追加）。
4. **文案口语化**：不说「相对湿度 75%」，说「潮湿闷热，身上发黏」；不说「辐照强度」，说「紫外线强」；不说「风力 6 级」，说「风偏大，帽子容易吹走」。
5. 优先级分层：气象风险类预警置顶（红色醒目标）→ 出行穿搭 → 游玩安排 → 随身物品；同类条目多选时并列显示，不是只取一个。
6. 完全保留原模块的「服务端 20min TTL 缓存 + 7 天预报表格 + 失败降级文案 + 前端 0 技术实现字样」不破坏。

## 非目标

- 不引入新 NPM 包；不做客户端 JS 交互（维持纯服务端渲染）。
- 不接入额外第三方 API（保持仅 Open-Meteo 免费 forecast endpoint）；warnings/alert 字段不在免费 endpoint 中，因此「气象预警」由 weather_code + 极值字段组合**合成推断**（非真实官方预警，文案避免「官方发布」字样）。
- 不做逐小时预报、不做分钟级降水、不做个性化用户画像。
- 不改动除 Weather.astro 外任何业务文件（index.astro 引入 Weather 的位置不变；spec/tasks/review 文档除外）。

## 功能需求（FR）

### FR-01 结构分层：基础卡片 + 4 类动态建议块

基础天气卡片（保留+微调，不删除任何已有视觉信息）之后，按以下顺序渲染 4 块；**每块当且仅当条目数组非空时才出现**（整块 DOM 都不渲染，不是隐藏 CSS）：

| 层级 | 区块名 | 图标前缀 | 视觉样式 | 命中空值处理 |
|------|--------|----------|----------|--------------|
| 0（最高） | ⚠️ 风险提醒 | ⚠️ | 红框/白底红字/阴影加深 | 无风险 → 整块消失 |
| 1 | ✅ 出行穿搭 | ✅ | 正常卡片白底 | 空 → 整块消失 |
| 2 | ✅ 游玩安排 | ✅ | 正常卡片白底 | 空 → 整块消失 |
| 3 | 🎒 随身物品 | 🎒 | 正常卡片白底 + 条目用 emoji 开头 | 空 → 整块消失 |

### FR-02 条件触发文案库（7 大类，严格按条件表格映射）

在 frontmatter 新增 `buildAdviceEngine(ctx)` 纯函数，ctx 包含所有字段（current / todayDaily / humidity / wind / code 等）；返回 `{ risks, outfits, activities, carries }` 四个字符串数组。以下条件**全部多选匹配（互不覆盖，命中就 push）**，优先级仅在渲染顺序体现（风险先渲染）。

#### 降水类（5 条触发）
| 条件（ctx 字段） | 输出落点 | 文案（可微调但不得改变语义） |
|------------------|----------|------------------------------|
| todayDaily.precipProbMax ≥ 60% | activities + carries + outfits | 出行：大概率会下雨，尽量携带雨具；游玩：露天水景体验较差，优先室内场馆/地铁站厅避雨；随身：折叠伞/雨衣；穿搭：防水外套优先 |
| code ∈ [51-55] ∨ precip ∈ (0, 2] 毛毛雨/小雨 | outfits + activities + carries | 出行：有小雨，路面湿滑，走路注意防滑；游玩：露天喷泉观赏水雾感更强但镜头易沾水汽；随身：折叠伞 |
| code ∈ [61-67, 80-82] ∨ precip ≥ 5 中到大雨 | risks + outfits + activities + carries | 风险：降雨较强，注意避开环形路口低洼积水带；游玩：不建议长时间户外步行，Los Caobos 公园林荫路仍有泥泞；随身：雨衣，不建议长柄伞（风大） |
| code ∈ [95-99] 雷暴类 | risks + activities + carries | 风险：谨防雷电，不要在环形人行天桥、喷泉开阔处、大树下避雨；游玩：户外项目（若有）大概率关闭，优先 Sabana Grande 步行街室内走廊/地铁站；随身：切断无人机等升空设备电源 |
| todayDaily.precipProbMax ∈ [40, 60) 概率中等 | activities + carries（仅 2 项，不上风险） | 游玩：有一定降雨可能，行程宜留 20% 机动时间；随身：备折叠伞（不下雨也不重） |

#### 高温 UV 类（3 条触发）
| 条件 | 落点 | 文案 |
|------|------|------|
| todayDaily.tmax ≥ 32 | outfits + activities + carries | 穿搭：气温偏高，轻薄透气衣物优先，避免深色吸热；游玩：缩短户外连续停留，正午 (12:00-14:30) 优先 UCV 室内走廊、博物馆、地铁站空调区；随身：充足饮用水、防暑用品 |
| todayDaily.uv ≥ 5 | outfits + activities + carries | 穿搭：紫外线较强，长袖/披肩、防晒面罩都管用；游玩：若计划环形天桥长曝，中午时段请务必遮阴；随身：防晒霜 SPF50+、墨镜、遮阳帽 |
| todayDaily.tmax ∈ [28, 32) ∧ current.humidity ≥ 75 | outfits + carries | 穿搭：湿热闷热，建议速干面料避免棉质贴身；随身：多备 1 瓶水（广场仅周边有直饮水） |

#### 低温 & 温差类（3 条触发）
| 条件 | 落点 | 文案 |
|------|------|------|
| (todayDaily.tmax - todayDaily.tmin) > 8 | outfits + carries | 穿搭：昼夜温差大，短袖/长袖叠穿，方便随时增减；随身：包里放一件薄外套（傍晚看喷泉灯光常用） |
| todayDaily.tmax ≤ 10 | outfits + carries + activities | 穿搭：气温偏低，厚外套 + 围巾；游玩：儿童/老人减少户外连续时间；随身：便携暖贴（若有） |
| todayDaily.tmin ≤ 16 ∧ tmax ≤ 22 | outfits（轻量一条） | 穿搭：微凉，衬衫 + 薄外套组合比较合适 |

#### 风力类（4 条触发）
| 条件（km/h 换算：1 节 ≈ 1.85 km/h；5 级≈29-38；6 级≈39-49；7 级≥50） | 落点 | 文案 |
|------|------|------|
| current.wind ∈ [29, 39) 约 5 级 | outfits + activities | 穿搭：帽子容易吹落，紧身帽优于渔夫帽；游玩：环形天桥上风偏大，拍照别靠太近护栏 |
| current.wind ∈ [39, 50) 5-6 级 | outfits + activities + carries | 穿搭：不建议穿宽松长裙/衬衫；游玩：三脚架固定时请加重物（摄影者）；随身：帽子、眼镜绳固定 |
| current.wind ≥ 50 ≥7 级 | risks + activities + outfits | 风险：大风天气，远离环形路口广告牌、天桥悬挂横幅；游玩：Abra Solar 附近叶片风声较大、不建议长时停留；穿搭：收束好外套避免被风掀 |
| current.wind ∈ [15, 29) 有风（非极端） | outfits（轻量一条） | 穿搭：有风体感凉爽，薄外套比单件短袖更舒服 |

#### 晴阴类（3 条触发）
| 条件 | 落点 | 文案 |
|------|------|------|
| code === 0 晴朗 | activities + carries + outfits | 穿搭：阳光好，浅色衣物更出片；游玩：适合环形天桥日出日落全景 + 蓝调时刻喷泉灯光长曝；随身：防晒（别忘补） |
| code ∈ [1, 2] 大部/局部多云 | activities（轻量） | 游玩：光线柔和不顶光，最适合拍 Abra Solar/Fisicromía 这类色彩与材质的艺术作品 |
| code === 3 阴天 | outfits + activities + carries（轻量） | 穿搭：不晒，穿什么都舒服；游玩：无暴晒适合长时间户外步行 Los Caobos/Jardín Botánico 二选一；随身：背包里放把折叠伞以防万一 |

#### 雾/霾类（1 条触发）
| 条件 | 落点 | 文案 |
|------|------|------|
| code ∈ [45-48] 雾/轻霾 | risks + activities + carries | 风险：能见度下降，环形天桥看 Avila 山远景受阻；游玩：观景体验较差，建议改看 Sabana Grande 建筑细节或 UCV 室内走廊；随身：口罩（敏感人群） |

#### 合成预警类（非真实官方预警，基于极值组合，文案明确不出现「官方发布」字样）
| 组合条件 | 落点（risks 数组第一条） | 文案开头固定格式：【⚠️ 天气风险提醒】…… |
|----------|--------------------------|------------------------------------------|
| code ∈ 95-99 ∨ current.wind ≥ 50 ∨ (todayDaily.precipProbMax ≥ 85 ∧ precip ≥ 8) 三合一任一命中 | risks | 【⚠️ 天气风险提醒】今日存在雷暴/大风/强降雨的潜在风险，建议灵活调整行程，优先地铁站、室内走廊和购物中心等封闭环境，不要前往山区/低洼地带，密切关注实时变化。 |

### FR-03 地理场景扩展

Plaza Venezuela 的三类周边场景（命中时才 push，多选）：
1. **场景 A · 城市人文广场**（常驻，任何天气下基于极值追加 1~2 条广场专属建议，例如「喷泉夜景观赏时」「环形天桥」「人行道过街」）
2. **场景 B · 邻接绿地森林**（Los Caobos/Jardín Botánico，湿度>70% 或 code 小雨类时追加）
   - 湿度>70% 且温度≥24：carries 数组追加「🎒 绿地区域建议驱蚊液/防蚊贴（林荫区蚊虫较多）」
   - 小雨/中雨时 activities 追加「🎯 Los Caobos 公园林荫小径雨后泥泞，建议穿防滑鞋，避免走土路」
3. **场景 C · 沿海大都会（距海岸 ~25km）**（UV ≥ 7 ∨ 风力 5 级以上时追加）
   - UV ≥7 + tmax ≥28：activities 追加「🏖️ 若当日驱车前往海岸，注意海面紫外线反射比陆地更强；回到市区广场的喷泉处夜间体感会凉爽很多」（保持中立，不点名具体海滩名）
   - 风力 ≥5 级：outfits 追加「🧢 无论广场或海岸，今天宽檐帽都需要固定绳」

### FR-04 动态渲染 & UI 三标签形式

沿用用户给出样式：每块标题 = 「图标 标签名」（例如 `✅ 出行穿搭`），每块用 `<article class="rounded-[1.5rem] border ..."` 独立包裹；每块内部 `<ul>` 列表，无条目 → 整块 `{risks.length > 0 && <article>...</article>}` 条件渲染直接不输出 DOM。

### FR-05 失败降级保持

fetch 失败时（ok=false）保持原 FALLBACK 渲染；建议引擎此时用 FALLBACK 合成字段 + 常见加拉加斯气候值给出「基于常年气候的通用出行参考」3 条（穿搭薄长袖+长裤、随身折叠伞+防晒、游玩避开正午）；7 日表整个块消失。

## 非功能需求（NFR）

### NFR-01 零堆字（rule，原模块最大痛点）
`risks/outfits/activities/carries` 四数组任一为空 → 对应区块整个 HTML **完全不渲染**（包括标题、边框、padding）。检查方式：对 Weather.astro 模板区（第 184 行之后）用正则 `<article` 计数，手动确认当空数组时无对应 article。

### NFR-02 零气象术语（rule，文案口语化）
模板区 HTML 文案中，禁止出现：相对湿度、辐照强度、天气现象代码、WMO、Beaufort（蒲福风级）、概率密度、气温日较差、露点温度 等任何专业词；所有专业字段必须先经过 Label 函数翻译为自然语言。

### NFR-03 零技术暴露（rule，延续上一版规格）
模板区 HTML 中 `grep -i "open-meteo\|免费\|API\|密钥\|接口"` 必须 0 命中；frontmatter 实现代码允许 fetch URL 有域名（服务器端，不在 HTML 输出）。

### NFR-04 服务端缓存不变（rule）
上一版 `__PV_WEATHER_CACHE__` 的 globalThis Map + 20min TTL 结构保持原样，不改动，不改小 TTL。

### NFR-05 文案质量（rubric 0-5 阈值 ≥4）
- 2 分：条件表覆盖率 < 80%；只有单选匹配，多选触发时只显示一个；
- 3 分：条件表覆盖率 ≥ 90%，但存在堆字（不下雨仍显示「雨伞建议空」占位句）；
- 4 分：条件表 100% 覆盖 FR-02 所有条目，多选并列显示，地理场景追加正确，动态隐藏严格；
- 5 分：在 4 分基础上，每段文案里还能融入 Plaza Venezuela 专属地标（环形天桥、喷泉夜景、Los Caobos、Sabana Grande、UCV），不是放之四海而皆准的「注意防滑」通用句。

## 约束/假设/依赖
- **约束**：仅使用 Open-Meteo forecast endpoint 现有字段（不新增参数，不调用 marine/air-quality/historical 附加 endpoint），保持 0 密钥、0 新增包。
- **假设**：风力阈值使用 km/h（Open-Meteo 的 wind_speed_10m 单位是 km/h），不做 mph 转换；
- **依赖**：Weather.astro 保留现有 siteInfo.nearbyLandmarks[0]='Sabana Grande'、[1]='Los Caobos'（site.ts 已经更新）用于地理专属名词植入；
