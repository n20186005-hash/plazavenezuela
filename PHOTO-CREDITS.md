Se conservan los bytes originales; el CSS puede recortar el encuadre mostrado. El título, autor, fecha, fuente, licencia y aviso de encuadre aparecen junto a cada foto. No se crea ni se sustituye la escena. Las dimensiones, longitud y hashes de cada original constan en src/data/photo-provenance.json.

El texto y diseño originales del sitio tienen derechos separados. No se atribuye al sitio la autoría de las fotografías ni de las obras representadas.
